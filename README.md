# 🚀 Telegram Clone - Advanced Settings & Features

Um clone completo e sofisticado do Telegram, desenvolvido com **React Native (Expo)**, **Firebase** e uma **API de Chat customizada**. Este projeto traz uma experiência premium de usuário, focada em configurações avançadas, segurança e personalização.

## 🌟 Destaques do Projeto

Este projeto não é apenas uma interface de chat, mas um ecossistema completo com funcionalidades avançadas:

### 📂 Gestão de Conversas
- **Pastas de Chat**: Organize suas conversas em abas personalizadas (Trabalho, Pessoal, Não Lidas).
- **Filtros Avançados**: Filtre chats por tipo (Privado, Grupos, Canais) ou contatos específicos.
- **Configurações de Chat**: Ajuste o tamanho do texto, papel de parede dinâmico e comportamento de envio.

### 🔒 Privacidade & Segurança
- **Controle de Acesso**: Senha de bloqueio (Passcode) e Verificação em Duas Etapas (2FA).
- **Privacidade Granular**: Quem pode ver seu número, visto por último, foto de perfil e mensagens encaminhadas.
- **Gerenciamento de Dispositivos**: Veja e encerre sessões ativas em outros aparelhos.
- **Usuários Bloqueados**: Lista de bloqueio totalmente funcional.

### 🔋 Eficiência & Dados
- **Modo Economia de Energia**: Ativação automática baseada no nível de bateria para economizar recursos.
- **Uso de Dados**: Estatísticas detalhadas de uso de rede (Mobile, Wi-Fi, Roaming).
- **Limpeza de Cache**: Ferramenta de limpeza inteligente por categorias (Mídia, Arquivos, Outros).

### 💎 Experiência Premium & Business
- **Telegram Premium**: Vitrine de recursos exclusivos com design de alta fidelidade e sistema de assinatura simulado.
- **Telegram Business**: Ferramentas para empresas, incluindo horários de funcionamento e automações.
- **Carteira (Wallet)**: Gestão de ativos digitais, saldo e histórico de transações.

## 🛠️ Stack Tecnológica

- **Frontend**: React Native, Expo, React Navigation.
- **State Management**: React Context API (SettingsContext).
- **Backend/Auth**: Firebase Auth, Firestore.
- **Chat Real-time**: Custom Socket.IO Client.
- **Persistência**: AsyncStorage para configurações locais.
- **UI/UX**: Vanilla CSS (StyleSheet), Ionicons, Design System inspirado no Telegram.

## 🚀 Como Executar

1. **Clonar o Repositório**:
   ```bash
   git clone https://github.com/luanhayalla2/telegram-clone-master-main.git
   ```

2. **Instalar Dependências**:
   ```bash
   npm install
   ```

3. **Configurar Firebase**:
   - Adicione seu arquivo de configuração do Firebase em `src/config/firebase.ts`.

4. **Iniciar o Projeto**:
   ```bash
   npx expo start
   ```
